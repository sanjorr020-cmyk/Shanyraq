# Shanyraq — демо-сайт строительного магазина

Демо для показа владельцу. Точные данные (ассортимент, цены, доставка, фото) подставляются позже.

## Что внутри

- Next.js 16 + Tailwind CSS 4, статическая сборка (23 страницы).
- Мобильная версия в приоритете: закреплённая внизу панель «WhatsApp · Позвонить · Карта».
- Заказ и вопросы — через WhatsApp с готовым текстом, цены не публикуются.
- Список-смета: клиент добавляет товары и отправляет весь список одним сообщением.
- Калькулятор материалов (примерный расчёт, см. «уточнить» ниже).
- Поиск по товарам, каталог из 7 категорий, страницы бренды, для строителей, доставка, контакты, о магазине, политика, 404.
- SEO: title/description по страницам, разметка HardwareStore (без aggregateRating), sitemap.xml, robots.txt, фавикон, OG-картинка 1200×630.
- Места под Яндекс Метрику и GA4: ID вписываются в `content/site.json` → `analytics`.

## Как менять данные без программиста

Все тексты и данные лежат в `content/`:

| Файл | Что там |
|---|---|
| `content/site.json` | название, адрес, часы, телефон, WhatsApp, рейтинг 2ГИС, оплата, доставка, бренды, сегменты главной, ID аналитики |
| `content/categories.json` | категории, описания, обложки, список позиций |
| `content/calculator.json` | расход материалов для калькулятора, источники для проверки |

Правка: открыть файл в редакторе, поменять текст в кавычках, сохранить. JSON должен оставаться корректным (запятые, кавычки). Если сомневаетесь, пришлите правки в чат, внесём сами.

Логотип: файлы в `public/logo/`. Сейчас в шапке и подвале вариант 4 (горизонтальный), фавикон — знак (`app/icon.svg`). Замена: положить новый SVG с тем же именем.

Фото: заглушки в коде помечены текстом «Фото: … (снять)». Когда фото готовы, заменить `<Placeholder>` на `<img>` (см. `app/page.tsx`).

## Что помечено «уточнить»

- Категории и список позиций (`content/categories.json`, поле `_note`).
- Бренды: только названия, без логотипов. Полный список у владельца.
- Цены не публикуются (кнопка «Узнать цену и наличие»).
- Доставка: только «условия уточняйте в WhatsApp», без цен и сроков.
- Оплата: «оплата по QR-коду» из 2ГИС. Kaspi не указан.
- Остановка «ул. Дружбы» — со слов владельца, в 2ГИС её нет.
- Калькулятор: типовые значения расхода, не сверены с техлистами производителей. Источники для проверки перечислены в `content/calculator.json` и на странице калькулятора.
- Ссылка на карточку 2ГИС (`rating.url`) — поиск по названию, нужна прямая ссылка.
- Адрес сайта (`siteUrl`) — будет меняться после появления домена.
- Политика конфиденциальности — шаблон, проверить юристом, уточнить реквизиты оператора.
- Обложки категорий — сгенерированы ИИ (Pollinations), помечены в `content/categories.json` (`coverNote`). Заменить на фото магазина.
- Казахский язык: не переведён, структура под него не заложена.

## Фото, которые нужно снять в магазине

1. Фасад с вывеской (днём и вечером).
2. Зал: 2–3 ракурса, общий план.
3. Полка с сантехникой (крупно).
4. Полка с сухими смесями.
5. Стенд электроинструмента.
6. Крепёж и герметики (пена, силикон).
7. Полка с брендами: Alteco, Soudal, Ultima, Престиж, Knauf, Gardel.
8. Касса и вход.
9. Вход с улицы и вид на остановку (для «Маршрута»).
10. Сотрудник за прилавком (только с его согласия).

## Вопросы владельцу

1. Полный ассортимент и бренды, которые реально продаются.
2. Прямая ссылка на карточку в 2ГИС.
3. Условия доставки (зона, стоимость, сроки, есть ли своя машина).
4. Условия для строителей и бригад (опт, скидки по объёму).
5. Оплата Kaspi: принимаете или нет.
6. Реквизиты оператора для политики конфиденциальности.
7. Домен и аккаунты для аналитики (Яндекс Метрика, GA4).
8. Нужен ли казахский язык.

## Запуск локально

```bash
npm install
npm run dev        # разработка, http://localhost:3000
npm run build      # продакшн-сборка
npm run start      # запуск собранного сайта
```

## Проверки

- Сборка: `npm run build` проходит без ошибок.
- Impeccable detect по главной, каталогу, категории, поиску, калькулятору, для строителей, политике: без замечаний.
- Lighthouse mobile, главная (локальный прод-сервер): performance 96, accessibility 100, best practices 100, SEO 100.
