# План демо-сайта Shanyraq (этап 3)

Статус: демо для показа владельцу. Точные данные подставим позже. Всё, что не подтверждено, помечено «уточнить».

## 2. Блоки главной (сверху вниз)

1. **Шапка**: временный логотип (SVG по вывеске), телефон, кнопка WhatsApp, поиск, меню: Каталог, Калькулятор, Для строителей, Доставка, Контакты.
2. **Первый экран**: H1 + подзаголовок + 2 кнопки (WhatsApp «Узнать наличие», «Смотреть каталог»). Справа фото-заглушка: «Фото фасада с вывеской».
3. **Сегменты**: 4 плитки — «Ремонт в квартире», «Сантехника», «Электроинструмент», «Строители и бригады». Каждая ведёт в каталог или на `/builders`.
4. **Категории**: 7 плиток с обложками (сантехника, сухие смеси, электроинструмент, крепёж, герметики и пена, краски, инструмент). Пометка «уточнить» в коде.
5. **Калькулятор**: тизер «Сколько штукатурки или клея на вашу площадь» → `/calculator`.
6. **Бренды в наличии**: текстовые названия Alteco, Soudal, Ultima, Престиж, Knauf, Gardel. Без логотипов.
7. **Доверие**: «4.8 в 2ГИС · 68 оценок» со ссылкой на карточку, часы, способы оплаты, адрес.
8. **Доставка**: «Доставка по Караоткелю, Косшы и Астане — условия уточняйте в WhatsApp».
9. **Финальный призыв**: WhatsApp, звонок, «Маршрут».
10. **Подвал**: адрес, часы, телефон, WhatsApp, ссылки на разделы, политика, соцсети (заглушки).

## 3. Путь клиента

Вход: поиск в Google «строительный магазин Караоткель», 2ГИС, прямая ссылка из Instagram → главная → категория или поиск → карточка товара → кнопка «Узнать цену и наличие» → WhatsApp с готовым текстом («Здравствуйте, есть ли в наличии: [товар]?»).

Для нескольких товаров: «Добавить в список» на карточках → панель со списком → одна кнопка «Отправить список в WhatsApp» (готовое сообщение со всеми позициями).

Калькулятор: площадь → материал → количество мешков или упаковок → «Отправить расчёт в WhatsApp».

Мобильная версия: закреплённая внизу панель с тремя кнопками: WhatsApp, Позвонить, Карта. Видна всегда.

Точки конверсии: одна главная кнопка (WhatsApp) на каждом экране, не больше двух кнопок рядом.

## 4. Оффер и тексты

H1 (черновик): «Стройматериалы и сантехника в Караоткеле»
Подзаголовок (черновик): «Ежедневно с 9:00 до 19:00. Ответим в WhatsApp: подскажем наличие, сравним варианты. Цены — по запросу».

Правила текстов: только проверяемые факты (2ГИС, ваши ответы). Никаких «лучших цен», «гарантии», «самых низких», «быстрой доставки» без условий. Цифр скидок и сроков доставки нет.

## 5. Стиль

- **Направление**: практичный и спокойный, «магазин, который знает товар». Без люкс-оформления. Swiss-минимализм из ui-ux-pro-max (категория «строительство»). Рекомендации генератора для «премиум» (Liquid Glass, Cormorant) не берём: для строймагазина не подходят.
- **Палитра**:
  - фон `#FFFFFF`, светлый блок `#F5F5F3`;
  - текст `#1C1B1A`, вторичный текст `#6B6B6B`;
  - акцент, кнопки: красный `#C8102E` (из вывески), белый текст на нём, проверим контраст ≥ 4.5:1;
  - вспомогательный: синий `#1E4E8C` (знак на вывеске), для ссылок и плашек.
- **Шрифт**: Golos Text (кириллица, Google Fonts). Inter не используем по правилам проекта.
- **Иконки**: SVG (Lucide), эмодзи не используем.
- **Фото**: общие блоки (первый экран, «Для строителей») — стоковые фото строек и инструментов без постановочных людей (Unsplash / Pexels, если разрешат сеть). Товары — заглушки до съёмки (см. раздел 8).
- **Сетка**: поля 16px на телефоне, 2 колонки карточек на мобильном, 4 на десктопе.

## 6. Технический план

- **Стек**: Next.js (App Router) + Tailwind, статическая генерация, next/image (WebP/AVIF), ленивая загрузка с заглушкой фиксированного размера (без пустых плиток и сдвигов).
- **Контент**: все категории, товары, контакты и тексты в `content/*.json`. Инструкция для владельца — в README.
- **Локальное SEO**:
  - title и description на каждой странице под запросы «[товар] Караоткель», «строительный магазин Караоткель», «сантехника Косшы»;
  - JSON-LD `HardwareStore` с адресом, часами и телефоном;
  - рейтинг 4.8 показываем текстом со ссылкой на 2ГИС, без `aggregateRating` в разметке (Google не засчитывает рейтинг без отзывов на своём сайте).
- **Служебное**: sitemap.xml, robots.txt, favicon, OG-картинка 1200×630 (превью в WhatsApp и Instagram).
- **Аналитика**: места под Яндекс Метрику и GA4, ID через переменные окружения (вставите позже).
- **Калькулятор**: площадь × расход × слой ÷ упаковка. Расход — из технических листов производителей, у каждого коэффициента указан источник. Результат подписан «примерный расчёт».
- **Список заказа**: хранится в браузере (localStorage), текст для WhatsApp собирается через `wa.me`.
- **Политика конфиденциальности**: шаблон для форм (имя и телефон). Юридическая проверка нужна отдельно.
- **Казахский язык**: ключи текстов по языкам, русский по умолчанию. Переводов пока нет.
- **Проверка**: Lighthouse mobile, цель 90+. Результат покажу честно, даже если не дотянем.
- **Деплой**: Vercel, адрес `*.vercel.app`, без домена.

## 7. Что помечено «уточнить»

- Категории и список товаров (кроме названий брендов из фото).
- Цены: не показываем, везде «узнать в WhatsApp».
- Доставка: условия, зона, стоимость — только «уточняйте в WhatsApp».
- Оплата: «оплата по QR» из 2ГИС, без логотипа Kaspi. Kaspi помечен «уточнить».
- Остановка «ул. Дружбы» (со слов владельца, в 2ГИС её нет) — «уточнить».
- Логотип: временный SVG по фото вывески.
- Соцсети: заглушки, ссылок пока нет.
- Опт: проценты скидок не пишем.

## 8. Фото, которые нужно снять в магазине

1. Фасад с вывеской (днём и вечером).
2. Зал: 2–3 ракурса, общий план.
3. Полка с сантехникой (крупно).
4. Полка с сухими смесями.
5. Стенд электроинструмента.
6. Крепёж и герметики (пена, силикон).
7. Полка с брендами: Alteco, Soudal, Ultima, Престиж, Knauf, Gardel.
8. Касса и вход.
9. Вход с улицы и вид на остановку (для «Маршрута»).
10. Сотрудник за прилавком (только с его согласия).

Пока на месте этих фото стоят заглушки с подписью, что снять.

## 9. Обложки категорий (AI)

Сгенерировать 7 обложек через Pollinations: реалистичное фото в одном стиле, светлый фон, мягкий дневной свет, без надписей, логотипов и брендов. Карточки товаров — только заглушки. В коде каждая обложка помечена «AI, заменить на реальное фото». Показываю все обложки одной страницей, плохие перегенерируем.

Сейчас `image.pollinations.ai` недоступен (сетевое правило), поэтому нужен разрешённый хост.

## 10. Решения, которые нужны от вас

1. **Фото товаров с сайтов производителей.** Ваше указание противоречит исходному правилу «фото не копировать», и у производителей есть авторские права. Предлагаю: на демо — заглушки и стоковые фото, после съёмки — свои. Подтвердите.
2. **Бренды.** Только текстовые названия, без логотипов брендов (это товарные знаки). Подходит?
3. **Калькулятор.** Сейчас найти расход из технических листов и дать список с источниками, или сделать структуру с заглушками?
4. **Сеть.** Разрешить в окружении хосты: `image.pollinations.ai` (обложки), `images.unsplash.com` (стоковые фото), `vercel.com` и `api.vercel.com` (деплой). Google Fonts уже доступен.
5. **Палитра.** Красный `#C8102E`, графит, синий, белый — подходит?
6. **Остановка «ул. Дружбы».** Оставить как «рядом» с пометкой «уточнить» или убрать?

После ответов на эти вопросы перехожу к этапу 4.
