# CLAUDE.md — правила проекта Shanyraq

## Исключения из правил

- **Адрес и телефон магазина указываются полностью** (включая номер дома и телефон в настоящем формате). Правило taste-skill «скрывать номер дома и телефон» здесь не действует: это реальный публичный магазин, данные из 2ГИС, без них не работают маршрут и звонок. Решение владельца проекта, зафиксировано в чате.

## Проект

- Сайт: Next.js 16, Tailwind 4. Данные в `content/*.json`.
- Прод: проект Vercel `shanyraq-demo`, защита входа отключена (демо для владельца).
- Ветка разработки: `claude/hopeful-dirac-3diwk3`.

## Фото

- Общие блоки (первый экран, «Для строителей», «Доставка», «О магазине») — стоковые фото Unsplash или Pexels. Для каждого кадра в README указывается ссылка на страницу с лицензией.
- Заглушки оставляются только в карточках товаров.
- Фото производителей не используем (авторские права).
- Генерированные ИИ-картинки используем только для обложек категорий, помечены в `content/categories.json`.
